# Interpretation and responsible use
Workflow: generate data, run Python summaries, execute MySQL queries, then build the Power BI model and measures.

Explore subject and term differences, attendance bands, cohort comparisons and score distributions. The generator intentionally creates a modest association between attendance and scores; this is synthetic and not causal evidence. A rule-based support flag should prompt human review only, never automated grading, exclusion or labeling.

Display sample sizes, define the pass mark, account for missing assessments, compare equivalent cohorts, and involve educators in interpretation. Keep personally identifiable student data out of public repositories.
